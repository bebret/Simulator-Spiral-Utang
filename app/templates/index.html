Simulator Spiral Utang

Alat literasi keuangan untuk merasakan sendiri bagaimana pinjaman berbunga tinggi dan taruhan online saling memperparah kerugian. Semua uang di sini fiktif.

Mulai simulasi

Cukup nickname. Tanpa password, tanpa data pribadi, tanpa uang asli.

Cara kerja simulasi

  1. Ajukan pinjaman. Biaya admin {{ admin_fee_pct|round|int }}% dipotong di depan, tetapi utang tetap sebesar pokok penuh.
  2. Putar slot simulasi. Peluang menang asli {{ win_prob_pct }}% dan pengali 2×.
  3. Maju beberapa hari dan lihat bunga {{ daily_interest_pct|round(1) }}%/hari menumpuk (bunga berbunga).
  4. Buka layar refleksi untuk melihat total biaya, total kerugian, dan grafik saldo vs utang.

Data disimpan di database simulasi dan dihapus permanen saat simulasi direset. Tidak ada merek, tautan, atau layanan keuangan asli di aplikasi ini.
